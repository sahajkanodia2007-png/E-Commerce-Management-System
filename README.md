# E-Commerce Management System (Java)

A console-based Java OOP project inspired by the structure of a loan-management application, adapted for an online store.

## Features
- Product catalogue and search
- Customer registration
- Shopping cart with quantity validation
- Checkout and order creation
- Inventory updates
- Order history and status
- Admin product/stock management
- Simple sales report
- In-memory storage using `ArrayList` (data resets when the program exits)

## Requirements
- Java JDK 17 or later

## Run
From this directory:

```bash
javac *.java
java Main
```
